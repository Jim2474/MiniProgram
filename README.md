# 德扑棋牌门店小程序 V23

本仓库包含：

- `backend/`：独立后端 API，Node.js 原生 HTTP 服务，本地 JSON 数据持久化。
- `miniprogram/`：微信小程序原生前端，可导入微信开发者工具。
- `legacy-web/`：V1 Web 原型保留目录。
- `docs/`：PRD 与验收记录。

## 后端运行

```bash
npm --prefix backend start
```

默认地址：

```text
http://localhost:3000
```

运行模式：

```text
APP_ENV=development  # 默认，允许本地模拟微信登录/支付/退款
APP_ENV=production   # 默认禁止模拟微信能力
ALLOW_MOCK_WECHAT=true  # 仅用于生产前沙箱演示，显式允许模拟微信能力
REQUIRE_AUTH=true       # 开发/沙箱环境也强制后台和员工接口校验员工会话
```

健康检查：

```text
http://localhost:3000/api/health
```

## 微信小程序运行

1. 打开微信开发者工具。
2. 导入项目目录：`miniprogram/`
3. 使用测试号或 `touristappid`。
4. 确保本地后端 `http://localhost:3000` 正在运行。
5. 如果开发者工具提示合法域名问题，确认本地设置不校验合法域名；项目配置已设置 `urlCheck: false`。

小程序包含四个 tab：

- 客户点单
- 员工端
- 商家后台
- 荷官升盲

## V23 新增能力

- 创建订单时同步生成待支付记录，支付账与订单状态分离。
- 支付成功逻辑抽为统一状态机，mock 支付和后续微信回调共用扣库存、赠积分、写流水逻辑。
- 重复支付请求幂等，不会重复扣库存或重复赠送积分。
- 生产环境支付接口返回真实微信预支付待接入提示，避免误用 mock 支付。
- 新增微信支付回调入口占位，未完成验签前拒绝处理。

## V22 新增能力

- 健康检查返回 `authRequired`，生产环境默认强制后台/员工接口鉴权。
- 后端支持 `x-staff-session` / `Authorization: Bearer` 员工会话校验。
- `/api/admin/*` 默认仅管理员可访问，`/api/staff/*` 默认要求员工/荷官/管理员会话，员工登录接口除外。
- 小程序统一 API 工具自动携带员工会话；员工端、后台端登录后写入全局会话。
- 后台端新增管理员登录入口。

## V21 新增能力

- 新增并发库存自测：同一低库存 SKU 同时加购时只允许一个请求成功，另一个返回库存不足。

## 说明

当前开发模式仍使用模拟微信登录、模拟手机号授权、模拟微信支付和模拟退款。生产模式默认禁止这些模拟能力；后续接入真实小程序生产环境时，需要替换微信登录、支付下单、支付回调、退款、鉴权会话，并将 JSON 数据持久化替换为数据库。
