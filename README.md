# 德扑棋牌门店小程序 V1 原型

这是根据 `PRD-德扑棋牌门店小程序-V1.md` 实现的可运行 V1 原型。当前版本用 Web 方式模拟微信小程序客户端、员工/荷官入口和 PC 商家后台，后端用本地 JSON 数据实现业务闭环，方便验收与后续迁移到真实微信小程序、微信支付和数据库。

## 运行

```bash
npm start
```

默认地址：

```text
http://localhost:3000
```

## 自验收

```bash
npm test
```

自验收会启动临时服务并验证：

- 员工二维码归属订单
- 库存不足不可下单
- 模拟微信支付成功后扣库存、发积分、写流水
- 后台看板与员工业绩
- 订单转存、客户取酒、员工确认取酒
- 预约提交与后台确认
- 退款后库存和积分回滚
- 升盲游戏创建与状态更新

## 入口

- 客户端：商品点单、购物车、我的订单、积分、存酒、预约
- 员工端：专属二维码、订单、业绩、存酒处理、积分调整
- 商家后台：看板、订单、商品库存、客户存酒、会员、预约、员工、日志
- 荷官端：轻量升盲、淘汰/恢复、代入统计

## 说明

当前支付为模拟微信支付：调用支付接口后立即进入支付成功回调逻辑。后续接入真实小程序时，需要替换登录、手机号授权、微信支付下单、支付回调验签和退款接口。
