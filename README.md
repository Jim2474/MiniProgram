# 德扑棋牌门店小程序 V58

本仓库包含：

- `backend/`：独立后端 API，Node.js 原生 HTTP 服务，本地 JSON 数据持久化。
- `miniprogram/`：微信小程序原生前端，可导入微信开发者工具。
- `legacy-web/`：V1 Web 原型保留目录。
- `docs/`：PRD 与验收记录。

## 后端运行

```bash
npm --prefix backend start
```

默认地址：

```text
http://localhost:3000
```

运行模式：

```text
APP_ENV=development  # 默认，允许本地模拟微信登录/支付/退款
APP_ENV=production   # 默认禁止模拟微信能力
ALLOW_MOCK_WECHAT=true  # 仅用于生产前沙箱演示，显式允许模拟微信能力
REQUIRE_AUTH=true       # 开发/沙箱环境也强制后台和员工接口校验员工会话
ALLOW_JSON_STORE_IN_PRODUCTION=true  # 仅沙箱演示；生产无 DATABASE_URL 默认拒绝启动
DATABASE_URL=sqlite://./backend/data/store.sqlite  # 单节点部署可用 SQLite 状态库
```

生产环境变量可参考 `.env.example`。`/api/health` 会返回 `runtime.deployment`，列出真实微信支付/登录和数据库配置缺口。

健康检查：

```text
http://localhost:3000/api/health
```

## 微信小程序运行

1. 打开微信开发者工具。
2. 导入项目目录：`miniprogram/`
3. 使用测试号或 `touristappid`。
4. 确保本地后端 `http://localhost:3000` 正在运行。
5. 如果开发者工具提示合法域名问题，确认本地设置不校验合法域名；项目配置已设置 `urlCheck: false`。

小程序包含四个 tab：

- 客户点单
- 员工端
- 商家后台
- 荷官升盲

- 自动验收覆盖生产 SQLite 启动和重启后读取持久化数据。
