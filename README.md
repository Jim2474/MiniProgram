# 德扑棋牌门店小程序 V8

本仓库包含：

- `backend/`：独立后端 API，Node.js 原生 HTTP 服务，本地 JSON 数据持久化。
- `miniprogram/`：微信小程序原生前端，可导入微信开发者工具。
- `legacy-web/`：V1 Web 原型保留目录。
- `docs/`：PRD 与验收记录。

## 后端运行

```bash
npm --prefix backend start
```

默认地址：

```text
http://localhost:3000
```

健康检查：

```text
http://localhost:3000/api/health
```

## 微信小程序运行

1. 打开微信开发者工具。
2. 导入项目目录：`miniprogram/`
3. 使用测试号或 `touristappid`。
4. 确保本地后端 `http://localhost:3000` 正在运行。
5. 如果开发者工具提示合法域名问题，确认本地设置不校验合法域名；项目配置已设置 `urlCheck: false`。

小程序包含四个 tab：

- 客户点单
- 员工端
- 商家后台
- 荷官升盲

## 测试

## V8 新增能力

- 客户个人中心支持模拟微信登录、会员切换和手机号绑定。
- 新会员自动初始化余额与会员等级，旧数据自动补齐缺省字段。
- 员工端展示最近六个月销售额和订单数。
- 荷官端支持按指定座位淘汰/恢复玩家。
- 荷官端支持代入手数减一和单手买入金额手动同步。
- 员工密码字段不再从 bootstrap、订单、扫码、员工业绩、人员管理、修改密码等接口返回。
- 员工相关操作日志净化密码字段，避免日志泄露。

## 已有核心能力

- 统一核销二维码令牌。
- 客户生成取积分、取酒、酒水券、中奖记录二维码。
- 员工扫码识别二维码并确认核销。
- 二维码核销自动更新积分、存酒、酒水券和中奖记录。
- 首页看板较昨日对比数据。
- 商品分类启停、SKU 上下架与编辑。
- 充值配置停用、会员等级编辑/停用。
- 积分配置：签到积分、有效期、兑换酒水券积分数。
- 抽奖规则：每日次数、冷却时间、消耗积分。
- 抽奖冷却真实拦截，奖品可停用。
- 员工账号密码登录。
- 客户预约列表与取消预约。
- 后台标记预约失效。
- 积分兑换酒水券。
- 过期存酒人工处理与流水。
- 咖位新增、占用、维护、消费金额。
- 荷官升盲计时器与语音提醒事件。
- 客户扫码员工二维码，写入扫码归属记录。
- 门店位置调用微信地图，客服联系调用微信电话能力。
- 中奖记录支持客户申请核销、员工确认核销。
- 商品分类新增、SKU 新增、商品筛选。
- 库存出入库申请、确认入账、驳回、库存流水。
- 后台查看消费记录、充值记录、扫码归属记录。
- 充值配置、客户充值、充值记录。
- 积分排行榜、签到送积分、积分抽奖。
- 酒水券兑换申请与员工确认。
- 会员等级、财务概览、营业明细。
- 员工修改密码、核销码查询、座位入座/淘汰/恢复。
- 后台抽奖配置、人员管理、咖位类型、升盲设置、系统设置。

## 说明

当前版本仍使用模拟微信登录、模拟手机号授权、模拟微信支付和模拟退款。后续接入真实小程序生产环境时，需要替换对应微信接口，并将 JSON 数据持久化替换为数据库。
