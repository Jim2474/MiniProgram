# V16 验收记录

日期：2026-06-08

## 本轮目标

- 对齐“做消费赠送积分 + 积分明细 + 后台手动增减，暂不做积分兑换、积分抽奖、排行榜”。
- 从客户、员工、后台三端移除不在 MVP 范围内的积分营销入口。

## 已完成

- 客户端隐藏积分排行榜、积分抽奖、积分兑换酒水券、酒水券二维码、中奖记录和中奖二维码入口。
- 客户端不再请求 `/api/leaderboard/points`、`/api/lottery/draw`、`/api/lottery/records`、`/api/coupons/exchange`。
- 员工端隐藏酒水券确认和中奖核销列表，仅保留积分/存酒二维码核销。
- 后台隐藏抽奖概况、奖品配置、抽奖开关和抽奖规则入口。
- 后台积分配置仅保留积分倍率、显示开关、签到开关、签到积分和有效期。
- 后端积分排行榜返回空结果并标记 `featureEnabled=false`。
- 后端积分兑换酒水券、积分抽奖、酒水券二维码、中奖二维码和抽奖配置写接口均返回暂未开放。
- 自动验收覆盖排行榜、积分兑换、抽奖暂不开放。
- 小程序静态校验覆盖客户、员工、后台三端不再暴露这些入口。
