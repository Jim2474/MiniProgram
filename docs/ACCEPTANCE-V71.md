# V71 验收记录

日期：2026-06-08

## 目标

补齐 Excel 中商品列表“显示商品列表、名称、价格、上架时间、状态等”的后台展示要求。管理员查看 SKU 列表时，应能看到商品状态和上架/创建时间，而不是只看到价格、库存和成本。

## 已完成

- SKU 数据结构新增 `createdAt` 和 `updatedAt`。
- 旧数据加载时自动给缺少 `createdAt` 的 SKU 补默认创建时间，并写回数据。
- 后台新增 SKU 时记录创建和更新时间；编辑 SKU 时刷新更新时间。
- 后台 SKU 列表展示价格、状态、上架/创建时间、成本、供应商、库存、预警和存酒有效期。
- 后端自验收覆盖 SKU 创建/更新时间字段。
- 小程序结构校验覆盖后台 SKU 状态和上架/创建时间展示。

## 剩余风险

- 历史种子 SKU 没有真实上架时间，旧数据迁移只能使用种子时间或当前加载时间作为默认创建时间。
- 后续可继续将“上架时间”拆成独立 `listedAt` 字段，便于反复上下架追踪。
