# V68 验收记录

日期：2026-06-08

## 目标

补齐 Excel 中“积分明细要显示消费/增减原因，并显示具体服务人员”的后台视角。老板查看积分流水时，应能区分消费赠分归属哪个员工，手动增减积分由哪个员工操作。

## 已完成

- 新增 `publicPointsLedger`，后台积分流水返回客户、操作员工、来源订单和服务人员上下文。
- 消费赠送积分流水通过来源订单追溯订单归属员工。
- 手动增减、二维码取积分等流水通过 `operatorId` 展示操作员工。
- 后台会员积分模块新增最近积分明细列表，展示客户手机号、变动积分、余额、原因、服务人员和来源。
- 后端自验收覆盖消费赠分与手动增减积分的服务人员上下文。
- 小程序结构校验覆盖后台积分明细展示。
