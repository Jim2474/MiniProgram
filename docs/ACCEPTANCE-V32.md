## 剩余上线风险

- 当前仍是单机 JSON Store 作为开发/沙箱持久化，生产环境需要接入正式数据库。
- 正式上线前仍需补齐手机号授权、生产商户号联调、微信平台证书轮换策略和真机回归。
- 当前二维码图片为服务端生成的 payload 二维码，不是微信小程序码；如需带小程序路径/scene 的小程序码，还需接入微信服务端接口。
