## 当前实现说明

- 当前版本是 Web 全栈原型，用于完成 PRD V1 业务闭环和验收。
- 微信登录、手机号授权、微信支付、退款均为本地模拟接口。
- 后端数据保存在 `data/store.json`，首次启动自动生成种子数据。
- 后续接入真实小程序时，需要替换微信登录、支付下单、支付回调验签、退款和数据库持久化。
