# V66 验收记录

日期：2026-06-08

## 目标

提升员工端取酒申请处理的可用性：员工确认或拒绝取酒时，必须能看到客户、商品和当前存酒余量，而不是只看到申请编号。

## 已完成

- 新增 `publicPickupRequest`，统一返回取酒申请的存酒、客户、商品和处理员工上下文。
- 客户历史取酒记录和后台/员工取酒申请列表都使用增强后的取酒申请结构。
- 员工端取酒申请列表展示客户手机号、商品名称、申请数量、当前存酒余量和申请编号。
- 后端自验收覆盖取酒申请返回客户、商品和存酒上下文。
- 小程序结构校验覆盖员工端取酒申请上下文展示。
