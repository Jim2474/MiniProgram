# V64 验收记录

日期：2026-06-08

## 目标

加固后台订单转存客户存酒，防止同一订单重复超额转存或转存订单外 SKU，避免客户存酒账与真实订单明细不一致。

## 已完成

- `publicOrder` 返回 `transferableItems`，包含每个订单 SKU 的已转存数量和剩余可转存数量。
- `/api/admin/orders/:orderId/transfer-storage` 校验 SKU 必须来自当前订单明细。
- 同一订单同一 SKU 的累计转存数量不能超过订单购买数量。
- 订单转存客户存酒流水写入 `sourceType: "order"` 和 `sourceId: orderId`。
- 后台订单列表展示可转存摘要，管理员转存前能看到每个 SKU 的剩余额度。

## 剩余风险

- 后台转存表单仍是全局 SKU picker，超额或订单外 SKU 由后端拦截；后续可按选中订单动态限制 picker 选项。
- 微信开发者工具模拟器仍需人工确认订单列表的可转存摘要在长订单号和多 SKU 情况下展示清晰。
