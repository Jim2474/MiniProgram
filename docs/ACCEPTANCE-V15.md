# V15 验收记录

日期：2026-06-08

## 本轮目标

- 对齐“先不做充值余额，只保留微信支付”的 MVP 范围。
- 移除客户侧余额充值入口，避免与当前点单微信支付主链路冲突。

## 已完成

- 客户端移除余额展示、充值配置 picker、充值按钮和充值记录。
- 客户端不再请求 `/api/recharge` 或 `/api/recharge-records`。
- 后台财务指标从充值收入改为微信支付营收。
- 后台页面隐藏充值配置新增、停用和充值记录展示。
- 后端充值记录接口返回空配置并标记 `featureEnabled=false`。
- 后端客户充值接口和后台充值配置写接口均返回“余额充值暂未开放，请使用微信支付点单”。
- 自动验收覆盖客户余额充值暂不开放、充值中心不返回可用配置。
- 小程序静态校验覆盖客户页隐藏充值流、后台隐藏充值配置操作。
