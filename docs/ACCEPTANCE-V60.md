# V60 验收记录

日期：2026-06-08

## 目标

把已明确暂不做的酒水券兑换、积分抽奖、中奖核销能力从后端也硬拦截，避免旧数据、旧二维码或直接调用接口绕过前端隐藏入口。

## 已完成

- 客户酒水券兑换申请接口返回“积分兑换酒水券暂未开放”。
- 员工酒水券确认核销接口返回“酒水券核销暂未开放”。
- 积分抽奖接口不再受历史配置开关影响，始终返回“积分抽奖暂未开放”。
- 客户中奖记录核销申请和员工中奖核销接口返回“中奖核销暂未开放”。
- 员工确认旧酒水券二维码、旧中奖二维码时直接拒绝，不会使用二维码或完成记录。

## 剩余风险

- 小程序前端已经隐藏券兑换、抽奖、排行榜和券/中奖核销入口；真实微信开发者工具中仍需人工确认入口不可见。
- 历史数据仍可能包含旧券或旧中奖记录，但 V60 已保证这些记录不能通过当前 API 被兑换或核销。
