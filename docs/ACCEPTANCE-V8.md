- 补齐客户个人中心的登录、手机号绑定和会员身份切换入口。

## 已完成

- 客户端新增个人中心区块，展示昵称、手机号、头像占位、会员等级和当前会员 ID。
- 客户端可调用模拟微信登录 `/api/wechat/login` 切换会员，并调用 `/api/user/bind-phone` 绑定手机号。
- 后端新会员初始化 `balance=0` 和 `memberLevel=普通会员`，并为旧 JSON 数据自动补齐缺省字段。
- 员工端展示 `/api/staff/performance/monthly?months=6` 返回的近六个月销售额和订单数。
- 荷官端支持座位格直接淘汰/恢复，并同步到升盲游戏当前人数。
- 荷官端支持 `buyin_minus` 减少代入手数，支持 `set_buyin_amount` 手动调整单手买入金额。
- 后端 `bootstrap`、订单、扫码归属、员工业绩、员工登录、员工列表、新增/更新员工、修改密码接口均不返回 `passwordHash`。
- 员工相关操作日志会净化密码字段，避免后台日志泄露密码。
