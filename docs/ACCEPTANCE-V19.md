- 旧员工数据自动补齐默认提成率。

- 后台 dashboard 的 `staffSales` 返回销售额、订单数、提成率、提成金额。

- 后台新增员工时可传入 `commissionRate`。

- 自动验收覆盖后台提成统计、员工月度提成统计、新增员工提成率。
