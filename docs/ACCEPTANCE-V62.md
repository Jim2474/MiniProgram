# V62 验收记录

日期：2026-06-08

## 目标

修正客户侧核销二维码的演示式固定行为，让客户生成积分二维码和取酒二维码时都对应真实选择。

## 已完成

- 客户端“生成取积分二维码”新增取积分数量输入。
- 小程序提交 `/api/verification-codes` 时使用客户输入的 `pointsQrAmount`。
- 每条客户存酒记录的“生成取酒二维码”按钮携带当前 `storageId`。
- 生成存酒二维码时按按钮所在的存酒记录提交，不再默认选择第一条可用存酒。
- 小程序结构校验新增真实积分二维码金额和按选中存酒记录生成取酒码检查。
