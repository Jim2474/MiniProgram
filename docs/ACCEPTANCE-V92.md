# V92 验收记录

日期：2026-06-08

## 目标

补齐 Excel 升盲设置中“背景图片可自定义上传”“logo 可以上传”“冠军背景图自定义上传图”的上传闭环。此前后台只能输入 URL 或选择系统图库，没有通过小程序直接选择本地图片并上传为可展示 URL。

## 已完成

- 后端新增 `/api/admin/assets/upload` 图片上传接口。
- 上传接口接收 `multipart/form-data`，限制 5MB，只允许图片类型。
- 上传图片保存到 `legacy-web/public/uploads`，返回 `/uploads/...` 可展示 URL。
- 上传操作写入后台操作日志。
- 小程序 API 工具新增 `wx.uploadFile` 封装，并自动携带员工/管理员会话。
- 后台升盲设置新增“上传背景图片”“上传 Logo”“上传冠军背景”按钮。
- 后台上传成功后自动回填对应 URL 字段，继续沿用保存升盲设置流程。
- 自动验收覆盖后端上传接口和后台三个上传入口。
