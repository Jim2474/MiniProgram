# 需求审计矩阵 V24

日期：2026-06-08

## 审计口径

- `完成`：已有后端接口、小程序入口和自动验收覆盖。
- `收敛`：Excel 原始项存在，但用户后续口头明确“先不做/暂不做”，当前已隐藏或禁用。
- `生产待接入`：本地业务闭环或接入点已完成，但上线前必须替换为真实微信/数据库/安全能力。

- 接入真实微信登录、手机号授权、支付 JSAPI 下单、支付回调验签、真实退款。
- 替换 JSON 文件为数据库，增加索引、备份、迁移和事务；V21 仅补了单进程写队列与原子写文件。
- 员工密码改为强哈希与安全初始化流程。
