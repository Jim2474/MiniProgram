# V23 验收记录

日期：2026-06-08

## 本轮目标

- 为真实微信支付接入补齐订单支付状态机和支付记录结构。
- 保持本地 mock 支付可验收，但生产环境不能误走 mock 支付。
- 增加支付幂等与回调验签占位，降低重复支付/重复回调风险。

## 已完成

- 创建订单时同步生成 `payments` 待支付记录。
- 新增统一 `markOrderPaid()`，集中处理订单置已支付、库存扣减、积分赠送和操作日志。
- `/api/orders/:orderId/pay` 在开发环境继续 mock 支付，并返回支付记录。
- 重复调用支付接口返回幂等结果，不重复扣库存、不重复赠积分。
- 生产环境支付接口将支付记录置为 `prepay_required`，并返回真实微信预支付待接入提示。
- 新增 `/api/payments/wechat/notify` 回调入口；未完成验签前拒绝处理，避免伪回调改账。
