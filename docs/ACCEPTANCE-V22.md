# V22 验收记录

日期：2026-06-08

## 本轮目标

- 为生产环境补上后台/员工接口的会话与角色权限闸门。
- 保持开发环境可继续快速演示和自动验收。
- 让小程序员工端、后台端登录后自动携带员工会话。

## 已完成

- 新增 `authRequired` 运行时开关：`APP_ENV=production` 默认开启，或任意环境设置 `REQUIRE_AUTH=true` 开启。
- 后端支持通过 `x-staff-session` 或 `Authorization: Bearer <sessionId>` 识别员工会话。
- `/api/admin/*` 默认要求管理员角色；`/api/staff/*` 默认要求员工、荷官或管理员角色，`/api/staff/login` 保持公开。
- 会话校验覆盖会话不存在、过期、员工停用和角色不足。
- 小程序统一 `utils/api.js` 自动携带 `staffSessionId`。
- 员工端登录成功后保存员工会话。
- 后台端新增管理员登录入口，登录成功后保存管理员会话并刷新后台数据。
