# V29 验收记录

日期：2026-06-08

## 本轮目标

- 将生产环境退款从纯 mock 推进到微信支付 V3 退款申请。
- 将“申请退款”和“退款成功后的库存/积分回滚”拆开，避免微信未确认前提前改账。

## 已完成

- 新增微信支付 V3 退款申请封装，调用 `/v3/refund/domestic/refunds`。
- `/api/admin/orders/:orderId/refund`：
  - 开发态保持 mock 一步完成退款，便于本地验收。
  - 生产态配置齐全时创建微信退款申请，记录 `processing` 退款单。
  - 退款申请中不提前标记订单为已退款，不提前恢复库存，不提前扣回积分。
- 新增 `/api/admin/refunds/:refundId/confirm`，用于退款成功确认后执行统一退款状态机。
- 退款确认后才执行：
  - 订单 `payStatus/orderStatus=refunded`
  - SKU 库存恢复
  - 消费赠送积分扣回或写入积分不足异常流水
  - 支付记录标记退款
- 退款申请幂等：同一订单已有未失败退款单时不会重复创建。
