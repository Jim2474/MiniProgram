# V72 验收记录

日期：2026-06-08

## 目标

补齐 Excel 中人员管理“新增或删除操作人员、修改员工密码但不可查询员工密码、操作记录留痕”的后台闭环。管理员应能在小程序后台看到员工列表，并完成启停、重置密码和删除操作人员。

## 已完成

- 后端新增 `DELETE /api/admin/employees/:employeeId`，采用软删除：员工状态置为 `disabled`，记录 `deletedAt` 和 `deletedBy`。
- 删除员工保留历史订单、业绩和操作日志关联，不物理移除历史数据。
- 管理员账号禁止删除，避免误删唯一后台入口。
- 员工删除、启停和重置密码均保持 `passwordHash` 脱敏，不在接口结果或操作日志中暴露。
- 小程序后台新增员工管理列表，展示姓名、角色、手机号、登录账号、状态、提成率和删除时间。
- 小程序后台支持启停员工、按表单密码重置、删除操作人员，并填写删除/停用原因。

## 剩余风险

- 当前删除为软删除，历史员工仍会出现在管理列表中，便于追溯业绩和操作记录；后续如需隐藏已删除员工，可增加状态筛选。
- 员工重置密码仍使用后台表单中的密码字段，生产上线前应配合管理员权限、强密码策略和审计告警。
