# V24 验收记录

日期：2026-06-08

## 本轮目标

- 在不引入复杂多仓库的前提下，补强单店 SKU 级库存系统。
- 增加成本、供应商和盘点单，满足商家日常库存管理。

## 已完成

- SKU 数据增加 `costPrice` 成本价与 `supplierName` 供应商字段。
- 旧数据加载时自动补成本价和供应商默认值。
- 后台新增 SKU 支持成本、供应商、预警库存、存酒有效期。
- 后台编辑 SKU 支持更新成本、供应商、售价、状态、预警和有效期。
- 新增 `/api/admin/stock-counts` 查询盘点单。
- 新增 `/api/admin/stock-counts` 创建盘点单，记录账面库存、实盘库存、差异数量。
- 盘点单入账后自动更新 SKU 库存，并写入 `stock_count_gain`、`stock_count_loss` 或 `stock_count_even` 库存流水。
- 小程序后台展示 SKU 成本、供应商和最近库存盘点单。
