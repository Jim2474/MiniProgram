# V7 二维码核销闭环验收记录

验收时间：2026-06-08

## 本轮新增范围

### 客户端

- 生成取积分二维码。
- 生成取酒二维码。
- 生成酒水券二维码。
- 生成中奖记录二维码。
- 展示当前二维码码值与历史二维码状态。

### 员工端

- 扫码或输入 `verify:xxx` 二维码码值。
- 员工扫码查看二维码类型、客户与关联业务对象。
- 员工确认核销二维码。
- 二维码核销后自动更新积分、存酒、酒水券或中奖记录状态。

### 后端

- 新增统一核销二维码令牌 `verificationCodes`。
- 二维码支持类型：`points`、`storage`、`coupon`、`lottery`。
- 二维码包含过期时间、使用状态、使用人和业务关联。
- 员工扫码查询与确认核销均写入操作日志。
