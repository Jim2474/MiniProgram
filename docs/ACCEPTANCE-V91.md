# V91 验收记录

日期：2026-06-08

## 目标

补齐 Excel 后台升盲设置第 41 行“语音自定义：开始提示音、结束提示音”的业务触发闭环。此前后台可保存开始/结束语音文案，荷官端也能查看配置，但创建本局和本局结束时不会生成对应事件。

## 已完成

- 后端新增升盲开始语音事件：创建本局时生成 `start` 事件。
- 后端在重开本局时重新生成 `start` 事件。
- 后端在淘汰到剩余 1 人并产生冠军时生成 `end` 事件。
- `start` 事件使用后台 `voiceStartText` 自定义文案，未配置时兜底“比赛开始”。
- `end` 事件使用后台 `voiceEndText` 自定义文案，未配置时兜底“本局结束”。
- 关闭语音提醒时不生成开始/结束事件，保持荷官端语音开关语义一致。
- 后端自验收覆盖创建本局开始事件、自定义开始文案和冠军产生结束事件。
